1. 새로운 몬스터 추가

다음과 같은 새로운 몬스터가 게임에 추가됩니다:

  • 불 타입: 파이어뱃, 플레어온
  • 물 타입: 워터맨, 해드론
  • 풀 타입: 리프킹, 버섯몬
  • 전기 타입: 전기캣, 라이트닝
  • 드래곤 타입: 드래고, 스케일드론

2. 도련장 확장

새로운 도련장이 추가됩니다:

  • 불의 도련장: 리더 - 화염 마스터
  • 물의 도련장: 리더 - 해양 여왕
  • 풀의 도련장: 리더 - 숲의 수호자

3. 새로운 이벤트

업데이트 후 다음과 같은 이벤트가 진행됩니다:

  • 신규 몬스터 포획 이벤트: 새로운 몬스터를 포획하면 특별 보상
  • 도련장 도전 이벤트: 새로운 도련장을 클리어하면 한정 아이템
  • 연속 로그인 이벤트: 7일 연속 로그인하면 레어 몬스터

4. 시스템 개선

다음과 같은 시스템 개선이 이루어집니다:

  • 게임 성능 최적화
  • UI 개선
  • 버그 수정
  • 서버 안정화
